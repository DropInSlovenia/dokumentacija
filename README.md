# DropInSlovenia
 
Aplikacija za raziskovanje Slovenije prek interaktivnega zemljevida. Uporabnik lahko izbere mesto ali regijo in si ogleda hotele, restavracije, turistične znamenitosti ter aktualne dogodke v bližini – vse v realnem času.

## Tehnologije
 
| Področje | Tehnologije |
|----------|-------------|
| Frontend | Next.js |
| Backend | Node.js, Express.js, Kotlin |
| Baza | MongoDB |
| Desktop (admin)| Kotlin, Compose Desktop |
| Organizacija | Jira, GitHub |
